# Sunset People

A bilingual directory of local groups and organizations in the Outer Sunset, helping residents discover and connect with neighborhood clubs, associations, and mutual aid groups.

## What is this?

Sunset People helps Outer Sunset residents find their people. Browse a curated, categorized directory of neighborhood groups and organizations, suggest groups that are missing, and discover fun things happening nearby.

## Features

- **Group directory** — Browse local organizations by category (mutual aid, arts, civic, recreation, and more)
- **Bilingual support** — Content available in English and additional languages
- **Suggest a group** — Submit a group that's missing from the directory
- **More Fun section** — Discover informal gatherings and social opportunities

## Tech stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
